Live Turn

Frontend consoleSends provider choices, runtime flags, system prompt, and PCM frames.
WebSocket session/ws/{session_id} validates providers and API keys.
VAD and ASRLocal manual VAD streams audio to ASR and emits asr.final.
Reviewed memoryLoads memory_blobs only when memory flag is enabled.
UserTurnNormalizes user text, history, timestamps, flags, and filtered memory.
Task routerSelects lane, route, reason, confidence, model, and optional phrase ID.
Frontend -> WebSocket -> VAD/ASR -> asr.final -> UserTurn -> Task router -> lane execution

Lane Execution

NO_LLM / CACHEDeterministic planner creates an AssistantPlan without model latency.
FAST_LLM / SMART_LLMRoute-aware prompt is rendered, then Gemini streams tokens.
ASYNCStarts post-call eval and returns a deterministic spoken acknowledgement.
AssistantPlanContains display text, spoken segments, route, validation, memory jobs, and metrics.
Router -> deterministic plan OR route-aware LLM prompt OR async post-call job -> AssistantPlan

Speech, Display, And Metrics

Speech guardBlocks known private-memory leaks before sentence TTS playback.
TTS streamingSpeaks safe sentence chunks and emits audio frames.
Frontend playbackReceives binary tts.audio_chunk and tts.done.
ObservabilityEmits turn.route, llm.response, validation, and metrics.turn.
AssistantPlan -> safe spoken segments -> TTS -> audio_chunk/done -> UI AssistantPlan -> display_text -> llm.response -> UI transcript Metrics -> turns.metrics_json -> right panel/session history

Post-Call Memory Review

Stored turnsUser and assistant turns are the source of post-call analysis.
Post-call reportSummary, sentiment, outcome, action items, memory candidates, quality flags.
Suggestions APIGET /sessions/{id}/memory-suggestions
Decision APIPOST /memory-suggestions/{id}/decision
Reviewed memoryAccepted suggestions are promoted into memory_blobs.
Future promptOnly reviewed, safe, relevant memory can enter future live prompts.
Post-call report -> memory candidates -> pending suggestions -> accept/reject -> reviewed memory -> future MemoryContext
